An OSINT platform that records what it could not establish.

OSINT-Sentry rates news sources, cross-references stories against other outlets, looks for accounts acting together, checks whether an image has been altered, and puts located events on a map. Every one of those steps can return no answer, and when it does it says which assumption failed.

The rule the whole system is built around:
No rating is given rather than a bad one.

A dashboard cannot tell the difference between a zero and nobody having looked. They are the same glyph on screen, and treating them the same way is how an analyst ends up confident about something nothing ever checked. So every engine here is allowed to decline, and a declined answer is stored and displayed as its own kind of result, with the reason attached.

What the five modules do

01 Source credibility

Reads real domain registration data over RDAP and inspects the live site for trackers, ad load and transport security. Scores are capped below the top tier on purpose: clean registration metadata is not evidence that a publisher is accurate.

02 Content analysis

Fetches pages, obeying robots.txt without exception, then extracts entities and topics and cross-references the story against other newsrooms. Published fact-checks are cited next to the rating but never move it.

03 Social graph

Scores accounts on reciprocity and shared-target overlap and groups those that consistently hit the same targets. Below a minimum amount of graph it records no score, because one unanswered mention is not evidence of automation.

04 Media forensics

Error level analysis, JPEG quantisation tables and metadata, on Pillow alone. Where an image's compression history makes error level analysis meaningless, it reports which assumption failed instead of producing a number that would look persuasive and mean nothing.

05 Geolocation and reporting

Resolves place names against a gazetteer compiled into the source, so no place name is ever sent to a third party. Reports are assembled from counted figures, and each one carries a section listing what it cannot show.

Audit trail

Every model write outside the excluded apps is recorded with the acting user, their IP and a field-level difference, so any number on screen can be traced back to the write that produced it.

Python and Node, and nothing else. The database is SQLite, the task queue uses a filesystem transport, geolocation resolves against a table in the source tree and image forensics needs only Pillow. There is no Docker requirement, no PostGIS, no Redis and no paid service. One optional feature, the published fact-check lookup, takes an API key you supply yourself; left out, it reports itself as switched off rather than failing.

What it does not do

This is the part most tools leave out, so it is stated plainly.

Claim not madeWhy
It does not determine whether a story is true. It measures corroboration, provenance and registration data. None of those are truth, and a story every outlet got wrong corroborates well.
Most engines are heuristics, not trained models. They are hand-written rules with published weights. The console labels the engine version on every record so heuristic output is never mistaken for a model's.
The one trained model reproduces a third party's ratings. The credibility model learns from Media Bias/Fact Check factual reporting ratings, which are one organisation's editorial judgement rather than ground truth. Its output says so every time.
It does not detect deepfakes. Image forensics covers recompression and metadata. Synthetic video detection is not implemented and is not claimed.
A detected cluster is not proof of coordination. A press pack on one beat and a paid amplification network look identical from the graph. Every cluster carries that caveat.

Built with

Django 5.2 and Django REST Framework on the backend, React 19 and Vite for the analyst console, Celery for scheduled work, and scikit-learn with LightGBM for the trained credibility model. The machine learning dependencies are optional and are not installed by default, so a fresh checkout brings all five modules up without them.
